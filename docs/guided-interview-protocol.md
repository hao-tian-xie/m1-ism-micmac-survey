# vt3 引导式专家访谈操作指南

当前采集版本：`vt3-guided-20261025`；问卷版本仍为 vt3。界面支持简体、繁体和英文。

## 这次落实了什么

| 最新方案中的环节 | 问卷中的实现 |
| --- | --- |
| 标准化理解 | 38项议题均有管理定义、物流示例、相邻议题区别及可展开的 ESRS 原文。 |
| 认识方向与未判断状态 | 正式来源任务前有两个交互练习，分别练习方向和未检查目标的记录方式。 |
| 先自由识别，再系统提示 | 每项来源先展示自由回忆框，再进入完整候选列表；回忆原文独立保存。 |
| 分组检查 | E/S/G 各组拆为每页5–7张卡片。不同题组与来源轮换领域和卡片顺序；返回时顺序保持稳定。 |
| 明确逐项判断 | 每个目标可记录有直接帮助、无明确直接帮助、无法判断或稍后检查。批量按钮处理当前页尚未判断的项目。 |

## 访谈前准备

研究者确认专家编号、主要工作领域、访谈时间和来源侧重，再从[题组分配表](vt3-task-plan.csv)选择链接。题组01–10提供不同来源组合；侧重方案约六成来源来自主领域，其余来自其他领域。每项来源的目标列表始终覆盖其余全部议题。

链接参数如下：

| 参数 | 可选值 | 含义 |
| --- | --- | --- |
| `batch` | 1–10 | 分配题组 |
| `focus` | `balanced`、`environment`、`social`、`governance` | 来源任务侧重 |
| `tasks` | 8、10、12 | 来源任务数量 |
| `lang` | `zh-CN`、`zh-HK`、`en` | 界面语言 |

例如：`?batch=2&focus=social&tasks=8&lang=zh-CN`。没有指定侧重和数量时，默认均衡分配12项来源。受访者可在本组中选择一项熟悉工作先做。

正式招募前，研究者安排2–3名熟悉物流、另行参加预测试的人员，试答环境、人员和治理各一项来源。记录他们如何理解词义、回忆经历、形成方向判断和选择答案。重点追问：

1. 您把这项管理工作理解为什么？
2. 您刚才想到的是哪段实际业务经历？
3. 来源工作通过什么方式帮助目标？中间经过了哪些工作？
4. 页面上的选项能否准确表达您的判断？哪里需要重新说明？

按预测试反馈修订易混淆的解释，并据实际耗时安排8、10或12项来源。

## 开场与练习

可以这样介绍：

> 这次想了解中小物流企业的 ESG 管理工作怎样互相支持。我们会逐项看管理工作的含义，再讨论改善这项工作会帮助哪些其他工作。请结合行业经验，考虑一家具有相关业务的中小物流企业。每个方向分别判断；不熟悉的目标可以记录为无法判断，准备稍后再看的目标保留为未检查。

先浏览三部分研究介绍，再交流业务经验。进入关系判断后，完成两个操作练习：已确认 A 帮助 B 时记录 A → B；尚未查看的目标保留为未判断。练习提供即时解释。

## 每项来源怎样主持

1. **理解来源。** 阅读简短定义。需要时展开物流示例、议题区别及 ESRS 原文。
2. **自由回忆。** 问“如果改善这项工作，您首先想到哪些其他工作会得到帮助？”记录专家原话或简短例子，最多1200字。暂时想不到时进入候选检查。
3. **逐页检查。** 每页只讨论当前5–7项。专家逐项选择；本页其余项目均无明确直接帮助或均不熟悉时，可用相应批量按钮。原有逐项判断继续保留。
4. **补充跨领域思考。** 需要时展开“跨领域再想一步”，询问资料交换、培训、资源安排或跨部门协作怎样帮助当前目标。
5. **确认关键关系。** 对一条跨领域、方向不清楚或涉及中间工作的联系追问。其他关系直接记录。
6. **确认本题。** 查看各类判断数量，再进入下一项来源。可通过来源目录返回修改。

关键关系可使用三个口头追问：

- 要把来源工作做好，需要哪些其他工作配合？
- 改善来源工作后，还会帮助哪些工作？
- 这项帮助具体怎样产生？若经过某项中间工作，还有哪些直接支持？

## 直接帮助与中间路径

“有直接帮助”指来源工作通过资料、人员技能、管理程序、资源或协调直接支持目标工作。

| 专家确认的情况 | 保存方式 |
| --- | --- |
| 来源直接帮助目标 | 方向记为 `1 / support`。 |
| 已检查，无明确直接帮助 | 方向记为 `0 / no_support`。 |
| 帮助完全经过另一项工作 | 选择“帮助完全通过另一项工作产生”，再选择中间工作。保存路径说明，来源到目标的直接方向记为 `0 / no_support`。路径中另外两个方向由各自的独立判断记录决定。 |
| 路径尚不清楚 | 选择“路径尚不清楚，留待确认”，直接方向记为 `null / unable`。 |
| 目标未检查 | 记为 `null / unreviewed`。 |
| 来源未分配且未单独追问反方向 | 记为 `null / unassigned`。 |

反方向在关键关系中另行询问和保存。与另一道来源任务已有明确判断发生冲突时，页面要求核对。自由回忆、路径说明与各方向判断分别保留，便于后续解释和追问。

## 节奏、回顾与暂停

30–45分钟的访谈可先用约5分钟介绍与练习，再分三段完成来源任务，最后集中补充关键关系与遗漏。每段结束时，回顾页展示最近记录的来源和各类判断数量。可以返回核对方向、补充业务例子，或自然停顿后继续。

草稿保存在当前浏览器；刷新后可经研究介绍和“继续填写”回到未完成位置。当前采集版本使用独立草稿键，练习完成情况、候选页位置、回忆文本及分段回顾状态一起恢复。

## 汇总与二轮追问

从后台导出包含逐项状态的完整 JSON 后，可以运行：

```sh
node scripts/report-expert-coverage.mjs export.json coverage.json 3
```

最后一个参数是研究者设定的每方向独立判断目标数，可按研究安排修改。工具汇总本轮采集版本、同一题库修订的记录，按专家编号统计，同一专家对同一方向重复作答时采用最近一次覆盖该方向的记录。输出包括促进、无明确促进、无法判断、未检查的数量，以及需要补充判断或存在分歧的方向。缺少专家编号及其他采集版本的记录分别计数。

研究者据此选择二轮追问对象：先补充判断不足的来源和方向，再讨论关键分歧与中间路径。每次新增判断继续保留专家编号、来源、目标、方向和解释。
