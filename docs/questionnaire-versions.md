## 访谈与分配

题库保持38项：环境19项、社会12项、治理7项。每项提供管理定义、物流示例、相邻议题区别和完整ESRS原文，原始名称、来源、类别及稳定ID沿用原配置。原7道业务经验与遗漏问题继续保留，均可在访谈中记录或补充。

当前流程：研究介绍 → 专家信息与分配 → 业务经验 → 两个操作练习 → 来源任务 → 检查与补充 → 一次提交。

分配方案 `vt3-background-overlap-v2` 支持01–10题组、四种来源侧重及8/10/12项任务，共120套方案。侧重领域约占六成来源，其余来源跨领域分配。均衡12项方案的来源组合沿用初始vt3，每个来源在十个题组中出现3或4次。受访者可选择本组一项熟悉工作先做；其余来源保留。

每项来源先自由回忆，再按E/S/G拆分为5–7项目标页，覆盖其余全部37项目标。领域及卡片顺序按题组与来源轮换，返回时保持稳定。8项任务在第3、6项后回顾；10项在第4、7项后；12项在第4、8项后。

研究者按专业背景和访谈时间安排来源，并核查实际有效判断、无法判断、尚未检查及独立专家覆盖。分配表由 `node scripts/build-guided-task-plan.mjs` 生成，见[vt3题组分配表](vt3-task-plan.csv)。

## 判断与路径

| 输入 | 保存规则 |
| --- | --- |
| 目标有直接帮助 | `1 / support`。 |
| 已检查，无明确直接帮助 | `0 / no_support`。 |
| 无法判断 | `null / unable`。 |
| 稍后检查 | `null / unreviewed`。 |
| 来源未分配且未单独追问 | `null / unassigned`。 |
| 整项来源无法判断 | 本题所有外向目标记为 `null / unable`，清除目标选择和关系说明，保留自由回忆文本。 |
| 关键关系完全经过中间工作 | 保存 `linkType: via` 与 `viaId`；来源到目标记为无明确直接帮助。中间路径的其他方向按独立判断记录。 |
| 关键关系路径尚不清楚 | 保存 `linkType: unclear`，该直接方向记为无法判断。 |
| 单独反向追问 | 独立保存目标 → 来源的判断；与已有明确判断冲突时返回核对。 |

同一页可同时保留明确判断、无法判断和未检查。批量按钮只更新当前页尚未判断的目标。来源状态由逐项目标状态生成；含待检查项的来源可明确确认并保留其状态。

自我关系沿用原约定：直接矩阵对角线为0，初始含自达关系矩阵对角线为1；对角线不计入方向覆盖。SSIM的V/A/X/O在两个方向均有明确0/1判断时编码，含未判断方向的配对保留已有单向值和空值。

## 数据与兼容

- 当前使用 `protocolVersion: vt3`、`wordingVersion: vt3-guided-20261025`、`collectionMethod: guided-recall-pages-and-paths-vt3`。
- 每项来源保存 `freeRecall`（最多1200字）、`recallStatus`、完整 `targetReviews`、派生来源状态和兼容的分组状态。
- 每项来源可记录一条关键关系：`targetId`、`note`（最多800字）、`reverse`、`linkType`、`viaId`。
- 保存来源分配和实际呈现顺序，练习完成情况及回顾节点记在参与者记录中。
- 服务器验证来源记录并生成方向矩阵、状态矩阵、配对行与覆盖数量。提交的派生数组须与来源记录一致；客户端可省略派生数组。
- 进度单位为 `source-tasks`，统计已确认的来源记录。目标方向覆盖单独按各判断状态统计。
- 后台详情、JSON及CSV的 `source_tasks_json` 保留自由回忆、逐项状态和路径。CSV在每份答卷首行保存完整来源记录。
- 原配置修订0的题库与7道问题定义沿用原样。vt3的问题措辞独立呈现；管理员修改的配置按其修订与问题版本读取。
- 初始vt3和v3答卷继续按原协议验证、读取。当前草稿使用独立存储键；语言、自由回忆、目标页位置、路径和回顾状态均可恢复。
- `scripts/report-expert-coverage.mjs` 汇总当前采集版本、同一题库修订的导出记录，按专家编号与方向去重，列出补充采集目标和分歧方向。

## 验证与恢复

### 三级字号修订 `vt3-type-20261026`

所有页面共用 `typography.css` 的三个字号变量：`--font-size-title: 28px`、`--font-size-section: 20px`、`--font-size-body: 16px`。介绍、问卷、检查、回执、填写指南与后台均沿用这三个字号。屏幕宽度改变时通过换行和布局适配；题目与说明不再自动缩字。

此修订只调整排版及资源缓存标记，文案、题库、分配、判断规则和草稿存储键沿用上一版。

### 页面文案修订 `vt3-editorial-20261025`

程序版本为 `1.7.1-vt3`。三语页面按“当前问题 → 必要解释 → 操作与结果”整理，增加三步流程、四种回答的含义、批量操作范围，以及卡片内的分层标题。反向问题显示两项工作的名称。无可说明的目标时，确认页说明可返回修改或直接确认。

本次修订保留38项原始题库、7道访谈问题原文、采集协议、矩阵编码和草稿存储键。页面资源使用新的缓存标记；数据中的 `wordingVersion` 继续表示现有采集协议修订。写作依据及三语核对规则见[问卷文案指南](writing-guide.md)。
